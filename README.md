# Hash Snowflake

入力した言葉から、その言葉だけの雪の結晶を生成する Web アプリです。
同じ言葉からは何度でも同じ結晶が、1文字でも違えばまったく別の結晶が生まれます。

## 特徴

- **言葉ごとに決まった結晶**：入力を SHA-256 でハッシュ化し、その値をシードにした乱数で形を決めるため、同じ言葉なら毎回同じ結晶になります
- **雪らしい形**：枝の型（樹枝状・シダ状・板状）や飾りを重み付きで選び、飾りの数や枝の量をルールで整えています
- **必ず六方対称**：1/12 の扇形だけを描き、鏡映と 60° ずつの回転で全体を組み立てます
- **成長アニメーション**：結晶が中心から育っていく様子を表示します（OS で動きを減らす設定にしているときは、成長させずにフェードで表示します）
- **SVG で保存**：完成した結晶を SVG ファイルとしてダウンロードできます
- **生成履歴**：最近生成した結晶を最大 10 件、24 時間までブラウザに残します
- **入力は外部に送らない**：ハッシュ化も履歴の保存（localStorage）も、すべてブラウザの中だけで行います

## 技術スタック

- [Astro](https://astro.build/)（静的サイトとして出力）
- TypeScript
- [Bun](https://bun.sh/)（パッケージ管理・スクリプト実行）
- 描画は SVG、アニメーションは Web Animations API

## 使い方

```bash
bun install
```

```bash
bun run dev
```

| コマンド | 内容 |
|---|---|
| `bun run dev` | 開発サーバーを起動する |
| `bun run build` | `dist/` に静的サイトを出力する |
| `bun run preview` | ビルド結果をローカルで確認する |
| `bun run check` | 生成処理の検証（同じ入力で同じ結果になるか、対称性、はみ出しがないか など） |
